# Что это за архив и как передать его Codex

Это **инструкции и шаблон конфигурации**, а не готовая реализация бота. Codex должен написать код на основе `tasks/001-bootstrap.md`.

## Состав

- `AGENTS.md` — краткие обязательные правила, которые Codex подхватывает из корня репозитория.
- `.agents/skills/telegram-bot-engineering/SKILL.md` — постоянный проектный skill (архитектура, деплой, безопасность, общение с пользователем).
- `tasks/001-bootstrap.md` — **первая задача**, содержащая пустое поле для того, что должен делать бот.
- `config/project.yaml` — начальная открытая конфигурация проекта, без секретов.
- `.env.example` — имена секретных переменных, без значений.

## Порядок действий

1. Откройте папку будущего репозитория проекта на компьютере.
2. Распакуйте **с сохранением структуры и скрытой папки `.agents`** содержимое архива в корень этой папки. Если файлы уже есть, сначала проверьте, чтобы не затереть важные данные.
3. Откройте файл `tasks/001-bootstrap.md` в текстовом редакторе. Между строками `НАЧАЛО ПОЛЯ ДЛЯ ПОЛЬЗОВАТЕЛЯ` и `КОНЕЦ ПОЛЯ ДЛЯ ПОЛЬЗОВАТЕЛЯ` обычными словами опишите, что должен делать бот. Можно оставить пустым — тогда Codex сделает только рабочий шаблон.
4. Откройте Codex для этой папки и отправьте ему:

   > Выполни `tasks/001-bootstrap.md` полностью. Следуй `AGENTS.md` и используй skill `telegram-bot-engineering` из `.agents/skills/telegram-bot-engineering/SKILL.md`. Выполняй технические операции самостоятельно, когда можешь. Все мои обязательные действия объясняй простыми пошаговыми инструкциями на русском. Не делай production-деплой без согласования.

5. Codex должен проверить локальные инструменты и сообщить, что ему действительно нужно от вас. **Никому не отправляйте токены Telegram и приватные ключи SSH.**

## Важно

- Этот архив ничего не деплоит и не меняет GitHub/Vercel автоматически.
- Бот в production будет работать на Vercel через webhook; dev-бот локально работает через Docker polling.
- GitHub branch protection зависит от прав и тарифа; Codex должен проверить фактическую возможность включения и не объявлять её настроенной без проверки.
- Бот на сервере IsHosting и Cloudflare Tunnel предусмотрены только на будущее.
