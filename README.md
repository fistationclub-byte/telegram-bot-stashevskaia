# Telegram-бот

По команде `/start` бот знакомит с Настей и предлагает посмотреть программу курса, вступить в бесплатный канал или записаться в список раннего доступа.

## Как проверить бота

**🔴 ДЕЙСТВИЕ ПОЛЬЗОВАТЕЛЯ — проверить ответ в Telegram**

- **Зачем.** Убедиться, что тестовый бот отвечает в вашем чате.
- **Что сделать.** Откройте [тестового бота в Telegram](https://t.me/stashevskaia_dev_bot), нажмите «Запустить» или отправьте `/start`, затем нажмите любую из трёх кнопок. Для проверки подсказки отправьте `/help`.
- **Если получилось.** Вы увидите приветствие и три кнопки по одной в строке. «Сайт курса» откроет сайт. Кнопка предзаписи предлагает выбрать тариф. Кнопка бесплатного канала пока показывает подсказку.
- **Если не получилось.** Напишите в этот чат, на каком шаге бот перестал отвечать. Токен присылать не нужно.
- **Как продолжить.** Если тестовый бот уже остановился, попросите Codex запустить его снова.

Тестовый бот останавливается после двух часов без сообщений и нажатий, максимум через восемь часов. Для запуска, остановки или просмотра состояния можно написать Codex «Запусти тестового бота», «Останови тестового бота» или «Проверь тестового бота». [Команды и настройки для сопровождения](deploy/local/README.md).

## Проверки и выпуск

`pnpm lint`, `pnpm format:check`, `pnpm typecheck`, `pnpm test`, `pnpm build`. Тесты используют имитацию Telegram API.

Из рабочей ветки открывайте PR в `development`. После проверки выпуска открывайте PR из `development` в `master`. Инструкции по развёртыванию и настройке рассылок находятся в [документации IsHosting](deploy/vps/README.md).

Пример отслеживания источника: посетитель TikTok запускает бота по ссылке `https://t.me/stashevskaia_bot?start=tiktok`. Бот сохраняет первый известный источник в Supabase и добавляет к ссылкам на сайт `source1=tiktok&source2=telegram`, `utm_source=tiktok&utm_medium=telegram`. Для новых кодов и кампаний используйте таблицу `bot.traffic_sources`. Тестовый бот с обычным локальным запуском использует отдельный SQLite-файл для предзаписи.
