# Локальный запуск

Codex выполняет эти команды из корня проекта. Для запуска нужны Node.js 24, pnpm 10, работающий Docker и Compose. Поддерживаются команда `docker compose` и отдельная `docker-compose`, в том числе при использовании Colima.

Тестовый токен хранится в закрытом локальном файле `.env.local` в переменной `TELEGRAM_DEV_BOT_TOKEN`. Используйте токен уже созданного тестового бота. Production-токен хранится отдельно.

Установите зависимости через `pnpm install --frozen-lockfile`. Для запуска выполните `pnpm dev:up`, для проверки состояния — `pnpm dev:status`, для просмотра журнала — `pnpm dev:logs`, для остановки — `pnpm dev:stop`.

Отдельный процесс на компьютере проверяет время последней активности и останавливает контейнеры проекта. Его журнал хранится в `.runtime/watchdog.log`. Параметры времени хранятся в `config/project.yaml`. Проверка выполняется раз в минуту по умолчанию.
